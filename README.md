## 🚀 Инструкция по развертыванию на GitHub Pages

1. **Создайте репозиторий на GitHub**:
   - Назовите репозиторий, например: `kharadj` или `kharadj-1000-houris`.
   - Репозиторий может быть публичным (`Public`).

2. **Загрузите файлы проекта в репозиторий**:
   ```bash
   git init
   git add .
   git commit -m "feat: Initial release of Kharadj & 1000 Houris meme site"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_НИКНЕЙМ>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin main
   ```

3. **Включите GitHub Pages**:
   - Перейдите в репозитории во вкладку **Settings** -> **Pages**.
   - В разделе **Build and deployment** выберите:
     - **Source**: `Deploy from a branch`
     - **Branch**: `main` / `/ (root)`
   - Нажмите **Save**.

4. **Готово!** Через 1 минуту ваш сайт будет доступен по адресу:
   `https://<ВАШ_НИКНЕЙМ>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`

## 💻 Локальный запуск

Просто откройте файл `index.html` в любом современном веб-браузере (Chrome, Edge, Firefox, Safari) двойным кликом мыши, либо через локальный сервер:
```bash
python -m http.server 8000
```
И перейдите по адресу: [http://localhost:8000](http://localhost:8000)
